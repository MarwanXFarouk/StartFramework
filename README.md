# Start Framework - React Practice Project

My first React project, built while learning the framework. I took a Bootstrap template (Start Bootstrap's "Freelancer") and rebuilt it as React components with client-side routing.

## Live Demo

https://start-framework-marwanfarouk.vercel.app

## Built With

- React + Vite
- React Router
- Bootstrap
- FontAwesome

## What I practiced

- Breaking a static template into reusable React components
- Client-side routing with React Router
- Deploying a Vite app to Vercel

## Run Locally

```bash
npm install
npm run dev
```
